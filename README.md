# Geförderte EigenheimRente – Rechner

Beratungs- und Antragsrechner der CEB Bankshop AG für die neue Förderung ab 2027
(Wüstenrot Tarif RD 2020 Premium): Anschlussfinanzierung absichern, Bauen/Kaufen oder
Modernisieren – mit Rechenbeispiel-PDF und befülltem Original-Antrag.

**Aufruf:** https://bankshopag.github.io/eigentumsrente/

Alles steckt in einer Datei (`index.html`), Bilder sind eingebettet.

## Neue Version einspielen
Neue `index.html` über **Add file → Upload files** hochladen und committen.
Die Datei nicht im GitHub-Editor (Stift) bearbeiten oder umbenennen – sie ist zu groß
für den Editor und würde dabei geleert.
